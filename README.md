 📊 Student Performance Data Analysis

 📌 Project Overview

This project analyzes the academic performance of **10,000 students using Microsoft Excel**.

The analysis focuses on factors such as study hours, attendance, assignment completion, learning style, engagement, stress level, social media usage, and sleep patterns.

 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Visualization
- Dashboard

 🔍 Analysis Performed

- Analyzed overall student performance
- Compared study hours with exam scores
- Analyzed attendance and assignment completion
- Compared different learning styles
- Analyzed student engagement and stress levels
- Studied social media usage and sleep patterns
- Categorized students into High Performer, Average, and At Risk groups

  📊 Key Results

- **Total Students:** 10,000
- **Average Study Hours/Week:** 27.13
- **Average Attendance:** 75.09%
- **Average Engagement Score:** 71.04

📈 Excel Dashboard

Created an Excel dashboard to visualize student performance, grades, attendance, study hours, engagement, and performance categories.
